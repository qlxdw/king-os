# king-os

32 位 x86 教学操作系统内核，运行在 Bochs/QEMU 等模拟器中。项目从启动扇区开始，逐步实现保护模式、分页、中断、线程调度、用户进程、系统调用和自制文件系统。

## 主要内容

```text
boot/       MBR、Loader、保护模式和内核装载
kernel/     内核初始化、调试和全局定义
thread/     PCB、线程创建、调度和同步原语
userprog/   用户进程、TSS、系统调用、fork/exec/wait/exit
device/     中断、键盘、定时器、IDE PIO 磁盘驱动
fs/         分区、inode、目录、文件描述符和文件读写
shell/      Shell、管道和重定向
command/    用户态外部命令，例如 cat
lib/         内核库、用户库和系统调用封装
```

## 构建

项目使用 `makefile` 生成启动镜像和内核镜像，默认工具链与 Bochs 磁盘镜像路径以 makefile 中的配置为准。构建前需要准备 32 位 x86 交叉编译工具链和 Bochs/QEMU 调试环境。

## 学习资料

完整的启动、调度、内存、进程、文件系统和 Shell 学习笔记见 [`docs/01_32位x86教学操作系统内核实现.md`](docs/01_32位x86教学操作系统内核实现.md)。文档按“硬件启动 -> 内核机制 -> 用户程序 -> 文件读取”的因果链组织，并标注了当前实现的边界。

## 项目边界

这是用于理解操作系统核心机制的教学内核，不追求完整 POSIX 兼容性。文件系统、进程隔离、错误处理和构建脚本仍有可继续完善的地方，学习时应结合源码和调试日志验证每条执行路径。
